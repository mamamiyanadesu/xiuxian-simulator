# 此劫难渡

寿元将尽的筑基散修，在真假机缘与人情算计中争取结丹。

手机优先的文字选择小游戏。仙侠底色，黑色幽默；隐患有征兆，后果有原因，玩家可以付出代价补救。

## 当前进度

- 第一版可玩：12 个原创事件节点、3 类隐患、连续故事、4 类结局、本地存档与因果复盘。
- 已采用用户确认的 D「山野行笺」界面；手机 360px 与桌面均经浏览器验证。
- 规则 v2：余寿 12，新增收尾预算，调查与冒险需要权衡；旧版存档保留，另开新版的一局。
- 21 项规则测试通过；完成 6,000 局固定种子策略比较。首版成功/失败流程及新版调查、预算与恢复已有浏览器验证。
- 仓库公开用于修改、版本记录和代码审阅；游戏网站尚未公开部署。

## 本地运行

需要 Node.js 22.18 或以上版本；本次验证环境为 Node.js 24.12.0、npm 11.6.2。

```sh
npm ci
npm run dev
```

打开终端显示的本机地址，默认是 `http://127.0.0.1:5173/`。首次点击“启程修行”；本地存档存在时可继续。不同浏览器、域名与端口的存档相互独立。

```sh
npm test          # 规则、剧情、存档的回归检查
npm run build    # 类型检查并生成 dist
npm run preview  # 预览构建产物，默认端口 4173
npm run balance  # 固定种子 1–1000，各跑六种策略
```

纯静态前端，无运行时框架、账号、服务器接口和模型调用。不要直接双击 index.html；请通过本机服务器运行。

## 怎样修改

| 内容 | 位置 |
|---|---|
| 初始数值、门槛、疗伤成本、征兆 | `src/config.ts` |
| 原创故事、线索、选项收益、风险 | `src/events.ts` |
| 结算、随机、剧情调度、终局 | `src/engine.ts` |
| 存档结构与恢复校验 | `src/types.ts`、`src/storage.ts` |
| 页面与交互、样式 | `src/main.ts`、`src/style.css` |
| 策略对比与回归测试 | `scripts/balance.ts`、`tests/engine.test.ts` |

修改规则后运行测试、构建与策略对比。影响旧存档语义时提升 `rulesVersion`；改变存档结构时提升 `version`，以免旧数据悄悄按新规则执行。

## 核心循环

观察机缘 → 调查或选择 → 获得收益与征兆 → 补救或继续 → 渡劫 → 因果复盘。

首版聚焦筑基冲金丹，目标单局时长 5—10 分钟；真实玩家阅读时长尚未验证。没有账号、付费、实时 AI、挂机或宗门经营。

## 开发约定

规则、事件数据与界面分离。随机结果可由固定种子复现，选择预览、实际结算与复盘共用数据。阶段性提交，后续功能用分支与 PR 管理。

## 参考与原创边界

玩法分析参考了 [月抛模拟器](https://arathustr.github.io/fun/3/) 的公开页面与源码，主要借鉴风险选择、隐藏信息及收益梯度。修仙世界、人物和故事为本项目原创，代码独立实现，不复制原作素材与文案。
