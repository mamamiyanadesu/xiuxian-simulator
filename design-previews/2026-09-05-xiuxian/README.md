# 界面方向预览

设计读取：手机优先的修仙文字选择游戏，以寿元、线索和选择为核心，仙侠底色、黑色幽默。

功能契约：三秒内看见当前修行状态、遇到了什么以及能选什么；视觉不掩盖代价与线索。样机局部按钮可演示反馈，不代表游戏规则已实现。

默认拨盘：视觉冒险度 7、动效强度 3、信息密度 5。选择时可调整并附文字建议。

| 方向 | 互斥设计要求 | 字体与布局 | 推荐原因或取舍 |
|---|---|---|---|
| A 旧籍朱批 | 暖色旧纸、朱批、书卷阅读 | 本地宋体标题、系统正文、纵向行文、直角选项 | 推荐；最贴合仙侠文字与伏笔阅读 |
| B 夜行灯录 | 深墨夜色、暖灯、冒险日志 | 无衬线与等宽数字、疏朗单栏 | 夜间氛围强，暗底需高对比 |
| C 宗门案牍 | 冷灰纸、墨线、功过簿、高密度 | 档案式分项、表格数字、硬边界 | 更突出规矩与利益的讽刺 |
| D 山野行笺 | 灰绿与米白、当代自然旅行手记 | 开放分区、柔和排版、轻快选项 | 更清爽，减轻困境压迫感 |

四个方向按独立任务与 CSS 作用域制作，统一页面用隔离的 iframe 嵌入，避免样式互相影响。

## 使用

`index.html` 为自包含预览入口。a.html 至 d.html 为各方向可编辑源文件；修改后运行仓库脚本 `python3 scripts/build-design-preview.py` 重建入口。

通过 qiaomu-design 本地预览服务打开时支持确认后回传。静态打开时可以选择、调整参数并复制选择文字回对话。推荐方向不会被自动提交。

用户已确认 D「山野行笺」，最终拨盘为视觉冒险度 7、动效 6、密度 5。这里保留的是设计过程样机；可玩游戏请按仓库根目录 README 启动。
