# 开发交接

更新于 2026-09-06。规则 v4 从零随机起步、隐藏调查与交替失控已实现，浏览器试玩与本地检查完成；远端提交以本分支和关联 PR 为准。

## 目标与确认事项

《此劫难渡》是手机优先的修仙文字选择小游戏。主角为寿元将尽的筑基散修；黑色幽默，离谱但有因果。首版 15 个事件节点、可调查和补救的隐患、少量连续故事、四类结局与真实历史复盘。

已先创建公开仓库 `mamamiyanadesu/xiuxian-simulator`，再进入实现。需求访谈、代表故事、PRD、四方向预览均完成。用户在预览中确认 D「山野行笺」，视觉冒险度 7、动效 6、密度 5。执行目标见 GOAL.md。

## 已完成与证据

- `src/events.ts`：15 个原创事件节点，另有静修保底节点；新增叮咚鸡、大狗叫、哈基米三条随机路线。
- `src/engine.ts`：集中结算、种子随机、预存风险结果、按遭遇期限安排契约后续、隐患来源、末次行动记录。

- `docs/validation/build.txt`：TypeScript 检查及 Vite 生产构建通过。
- `docs/validation/balance.json`：规则 v4 的 6,000 局固定策略结果，完整存档最大 6,229 字节。

## 当前交付：规则 v4

用户要求从 0 修为开始、随机首事件、每个事件一个不泄露信息的调查专属选项、>40 不恢复调查、>70 失控与自主选择交替，并增强事件趣味。已逐项实现，现有 15 个故事，保留 12 寿元并调整机缘回报。新增叮咚鸡、大狗叫、哈基米三个热梗事件，梗分别落在驿站垫付运费、护井灵兽换班和灵宠供粮账中。详见 `docs/REVISION-4.md`。当前选择性调查模拟成功 77.2%，开局有中风险时赌一次 72.5%；用户体验尚待复玩。存档结构 3、规则 4，旧 v1/v2/v3 均保留。

## 历史：规则 v3 有限调查

用户明确确认高心魔调查会失控随机执行选项。已加入初始/上限 2 次、每次 1 寿元、连续 3 次顺遂恢复 1 次、心魔 ≥40 停止恢复并使调查失控。规则默认值可调；完整边界、测试和浏览器实测见 `docs/INVESTIGATION.md`。存档结构版本 2、规则版本 3，使用 `cijienandu.save.rules3`，保留 v1/v2 旧键。当前 6,000 局中选择性调查成功 94.6%，开局赌一次 75.7%，不能代表真人胜率。

## 已知限制与后续建议

上一轮历史：根据用户反馈“调查即可轻松通关、余寿过多”，规则升至 v2：余寿 18→12，中风险收益 16/心魔 10/隐患概率 25%，高收益心魔降至 22，常规补救修为成本 10→6，部分值得调查的机缘收益提高至 14。收尾预算显示当前还能花多少寿元；调查和已调查选项不再自动高亮为推荐。新存档键为 `cijienandu.save.rules2`，旧键保留但不按新规则继续。

全部调查脚本成功 55.4%，选择性调查 95.7%，开局赌一次 76.8%；对应成功局平均余寿 1.69、2.27、3.35。资源压力已由规则验证，不能视为真实玩家胜率或紧张感已验收。下一步请用户试玩最新 v4（本段百分比为历史 v2），观察是否出现有意义的临场取舍；尚不增加新系统或继续机械压低寿元。

尚未测量移动网络冷启动与真实输入到绘制延时，未做真机触屏、屏幕阅读器或跨浏览器矩阵。P2 的额外路线、分享卡等不在本次范围。
